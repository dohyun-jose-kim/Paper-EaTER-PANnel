이 그림에서 구분한 책임
  • Execution plan: frontend가 선택지와 범위를 보여주고, 사용자가 설정·승인합니다. Backend는 승인된 요청을 처리합니다.
  • Review: backend가 비교 결과와 review 항목을 생성하고 frontend가 표시합니다. 사용자는 선택·수정·rerun 요청을 입력합니다. Backend는 응답을 별도로 기록합니다.
  • Independent calls: backend가 CLI 호출을 관리합니다. 사용자가 미리 연결한 계정·CLI 경로를 통해 선택한 model service가 요청을 처리합니다. 계정 정보는 논문 내용의 일부가 아닙니다.
  • 상자 사이 연결은 책임과 데이터 의존성을 나타냅니다. REST API, IPC, process 구성이나 authentication 구현을 선택한 것은 아닙니다.
  • Review 중 Apply는 차단됩니다. Review 종료에서 Apply까지의 정확한 전환과 실패 복구는 미승인 상태입니다.
  • 이 그림의 Compare는 논리적 역할입니다. 별도 LLM call을 자동 생성하거나 추가 실행 권한을 뜻하지 않습니다.
