Sequential / parallel 검토 결과
  • Call들은 독립적입니다. 동시에 실행할 수 있지만, call 수와 concurrency는 다르며 모든 call의 동시 실행을 보장하지 않습니다.
  • Candidate 묶음은 각 call의 결과를 보존하는 data collection입니다. 모든 call이 끝나야만 검토를 시작한다는 barrier가 아닙니다. 부분 결과 비교의 구체적 readiness 기준은 미정입니다.
  • Content, bibliography, source mapping, provenance는 결과의 구성 요소입니다. 서로를 순차 실행 단계로 나열하지 않았습니다. Naming proposal은 bibliographic information에 의존합니다.
  • 구조 비교 다음에 내용 비교를 한다는 순서는 유지합니다. Review 중에도 다른 paper 및 승인된 call/rerun 처리는 계속될 수 있습니다.
  • Reading과 manual handoff는 결과 사용의 별도 경로입니다. 한 경로가 다른 경로의 선행 조건이 아닙니다.
  • Apply는 active review 밖에서만 허용됩니다. Review 종료·최종 승인·Apply 전환, override 이후 완료 상태와 transaction은 미확정입니다.
